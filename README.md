# N Café website

A responsive café website built with React, Vite, Tailwind CSS and lucide-react. The page includes the café story, featured dishes, filterable menu and prices, combo offers, photo gallery, location, contact links and opening hours.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The café's photos and favicon are served from `public/`. Menu names, categories and prices are maintained in `src/data/menu.js`.
